# 清图任务

## 概述

自动从左到右依次清理未通关的地图关卡。适用于推图场景，支持多种 OCR 预处理模式以应对不同的关卡卡片样式。

---

## 配置要求

> 确保分辨率大于等于 **1280×720**，否则可能无法正常使用

---

## 工作流程

1. 停在任意关卡选择页面启动。
2. **回到章节起点**：反复点屏幕最左边的卡片（游戏会把它滚到屏幕左中位置，露出更早的关卡），直到最左的卡片不再变化。路过的卡片顺便核实状态。
3. **从左到右推进**：对每张还没核实的卡片点开面板判断：有「完成前置关卡解锁」记为未解锁；没有「特殊奖励」记为已通关；有「挑战」进战斗，有「观看」跳剧情。
4. 右边没有可处理的卡片时点最右边的卡片把视野往右挪，继续；视野不再变化且没有未解锁的关卡时结束。

## 识别模式

程序支持三种 OCR 预处理模式，可根据关卡卡片的实际样式选择合适的组合：

### 普通OCR

不做任何图像预处理，直接识别关卡名称。适用场景：背景和关卡卡片颜色与白色差异明显，文字清晰可辨。

### 除杂色OCR1（标准白色）

过滤掉非纯白色区域后再识别。适用场景：关卡卡片文字为标准白色，背景较复杂干扰识别。

### 除杂色OCR2（宽松白灰色）

同时保留白色与浅灰色区域后再识别。适用场景：关卡卡片文字为白色或浅灰色，或普通OCR/除杂色OCR1均无法识别时。

## 选项说明

| 选项 | 默认值 | 说明 |
|------|:------:|------|
| ⭐普通OCR | True | 使用普通OCR识别关卡名称 |
| ⭐除杂色OCR1 | True | 使用标准白色过滤后识别 |
| ⭐除杂色OCR2 | True | 使用宽松白灰色过滤后识别 |
| 战斗内点击自动 | False | 进入战斗检测到「行动结束」时点击右上角自动战斗按钮；默认依赖游戏内全局自动 |
| 自动使用体力药 | False | 体力不足弹出「情报拼图补充」时，只用调度室储存和情报拼图道具恢复，每次用 1 份，绝不使用坍塌晶条（第二页签的接入密钥是正常体力道具，会用）；关闭时体力不足会直接停止任务 |
| 借好友助战 | False | 部署界面自动借助战：我的人形里已上场同名角色先撤回（在地图上点中它再点「撤回人形」），再到好友助战按属性筛选、按战力从高到低找椎数达标的卡片，点空地格后点「部署人形」；阵容满了就点有人的格子顶替；没有达标的就不借 |
| 助战角色 | 威玛西娜 | 要借的角色名，须与游戏内显示一致 |
| 助战最低椎数 | 6 | 卡片左上角蓝圈里的数字下限 |
| 找不到就借战力最高 | True | 没有达标的指定角色时，切到「全部」按战力从高到低借第一个能部署的助战；列表里已有打勾（上一关借的还在场上）的就不再换 |
| 自动补满阵容 | True | 借完助战后顶部「部署人形 n/m」没满时，到我的人形按战力从高到低补人：选卡 → 点空地格 → 部署人形，直到满员 |
| 调试截图 | True | 把扫描、选关、战斗各阶段截图保存到 `screenshots/推图/日期/`，每个任务最多 400 张 |

> OCR 选项如果全部关闭，程序会自动回退到全部开启。
>
> 体力处理：「继续前进」或「作战开始」后若弹出体力不足窗口，脚本先按选项恢复或取消。点确认后弹窗不一定会关（用接入密钥兑换后它一直开着），脚本看右上角体力数字涨了就算成功，自己点取消关掉再继续；另外连续点 8 次「继续前进」都没进入战斗也会主动停止，不再无限循环。

## 选关顺序与分支

- 关卡名是「可选字母前缀 + 章-关」（3-1、SL-3-2、BH-3-4，前缀最多 4 个字符），主线和支线一视同仁，树上每个节点都会推，顺序只按 x 从左到右。
- 维护一个进度游标：某关核实已通关或刚打完后，只往它右边推。
- 未解锁的关卡先跳过，推完任意一关后重新判定；右边全是未解锁时停止并提示。
- 只有在面板打开时才按返回键关面板；选关页没有面板时按返回会退回章节页面。

## 部署界面的识别方式

- **卡片是谁**：`assets/card_avatars/<人形名>.png` 保存每个人形的卡片立绘模板，扫描卡片时直接比对立绘，不用逐张点开看名字。第一次见到的卡片会点一下、读左下角名字并自动存模板，之后就认识了。同一个人形换皮肤立绘不同，会另存为 `<人形名>_2.png`、`_3.png`……，比对时任一张像都算。模板名由 OCR 得来，偶尔错一个字（如 克兼妲），预筛时按模糊匹配处理，不会漏掉目标。
- **椎数**：OCR 认不出蓝圈里的小数字，用 `assets/support_badges/` 的二值模板比对。
- **地格**：用菱形模板在蓝色掩码上找地格中心，按「填充率」排序，空地格接近 1，站了人的被立绘挡住会更低；已上场单位用头顶的深色编号标签定位（标签下方 0.083 画面高）。
- **卡住的状态**：在地图上点过格子/单位后，右下角会变成「无法在该点位部署」「该人形无法撤回」，此时点「作战开始」只会弹出面板、战斗不会开始。脚本每次试点失败都会点一下离地格很远的空地取消选中，点作战开始后若还在部署界面也会清掉选中再点一次。

## 选关面板的判定

点开关卡卡片后读右侧面板：有「完成前置关卡解锁」是未解锁；没有「特殊奖励」说明首通奖励已领、算已通关；有奖励且有「挑战」/「观看」就去打。面板是带动画弹出的，「特殊奖励」常比底部按钮先出现，只看到奖励没看到按钮时会单独在右下角找按钮（实机上「观看」常只被框出一个「观」字，所以只读到「观」/「挑」也算数），再读几帧仍读不到就关掉面板重试，不会当作未解锁跳过（SL-5-3 曾因此被漏掉）。

未解锁的关卡在推过任意一关后都会重查，而且不受「只往右推」的游标限制；右边没关可推时还会回章节起点再核实一遍，确认全部仍未解锁才报错停止。

## 「使用整备室配置」下拉框

「我的人形」页签顶上有个「使用整备室配置」下拉框，和「好友助战」页签的属性筛选图标位置重叠。误点会展开「编队1…编队7」列表，选中某个编队后面板只显示该编队的人形，空编队会直接把场上阵容清成 0/n。脚本每次扫描卡片前都会检查面板里有没有「编队n」，有就把列表收起：想选的编队已经是当前项时点列表里的同一项不会收起（实录），这时改点标题；还开着就先选别的项再切回来。页签「我的人形 / 好友助战」偶尔会被 OCR 漏读一帧，脚本会多读几帧，再不行按固定位置点；兜底借战力最高前也会先强制切到好友助战页签再点「全部」。

阵容已满时要上助战，会逐个点地图上有人的地格，优先撤回上一关借的助战，否则撤回我方战力最低的人形腾位，再把助战部署到空出来的地格（直接点有人的地格只会选中那个单位，不会顶替）。

## 换助战要先撤回旧助战

场上同时只能有一个助战。借助战前脚本会逐个点地图上有人的地格，名字不在我方已上场名单里的就是上一关借的助战：是目标角色就保留，不是就先点「撤回人形」再去好友助战里借新的。我方已上场名单来自「我的人形」里打勾的卡片，立绘没认出来的会先点一下读名字。

按钮是「编入队伍」时表示地图上还选中着一个单位，点下去会用这张卡顶替它（实录：刚部署完的助战还处于选中状态，补人时把助战顶掉了）。脚本遇到它会先取消地图选中再重选卡片，仍是「编入队伍」就跳过这张卡。

## 阵容与助战（全局配置）

设置页里的「阵容与助战」是所有任务共用的：

| 选项 | 说明 |
| --- | --- |
| 编队名 | 整备室编队的名字（游戏里可自定义，默认 编队1）。留空就不切编队。编队最多 6 人，关卡只能上 4 人时用前 4 个 |
| 助战角色 / 助战最低椎数 | 要借谁、至少几椎 |
| 找不到就借战力最高 | 没有达标的就借「全部」里战力最高的 |

推图任务里只剩「借好友助战」开关。每关开战前的流程：

1. 打开部署面板，在「我的人形」的「使用整备室配置」下拉框里选中配置的编队；
2. 开了借助战：到好友助战里按规则选定一张卡（点一下核对名字）；
3. 回我的人形读出已上场的名单，再逐个点地图上的单位读名字，决定撤谁：上一关借的旧助战 > 和助战同名的我方人形 > 阵容已满时我方战力最低的；场上已经是要借的助战就保留；
4. 重新选中助战卡片，点空地格，「部署人形」；
5. 还有空位就按战力从高到低补满（选了编队就只剩编队成员），然后「作战开始」。

任务启动后只在第一次进部署界面时整理阵容；之后无论是「继续前进」连打还是从选关面板「挑战」进的下一关，游戏都沿用上一场的阵容（含助战），脚本只看一眼顶部人数没缺就直接开战（缺人才重新整理）。推完当前页面上所有可打的关卡后任务自动结束（剩下的都未解锁时会报错停止并列出关卡名）。

## 看门狗（防止无限卡住）

任务启动后会起一个独立线程盯着进度：每次点击、每条日志、每次换阶段都算一次进展。连续 120 秒没有任何进展就：

1. 把执行线程当前的调用栈记进日志（`[看门狗]` 开头），说明卡在哪个文件哪一行；
2. 把最后一帧存成 `screenshots/推图/<日期>/..._watchdog_N.jpg`（不受「调试截图」开关影响）；
3. 弹通知。会先区分是不是人为暂停：任务卡片上的「暂停」按钮、F9 热键或顶部暂停按钮都会让执行线程在 ok-script 里空转，界面上可能还显示「运行中」（实录：误点「暂停」后卡了 6 分钟），这种只提醒不自动继续；
4. 不是暂停、又停滞到 240 秒，就自动停止任务并在任务卡片上写明原因，不让它一直转。
5. 游戏窗口被最小化或移出屏幕时 ok-script 会暂停执行器，而且窗口恢复后不会自己继续（实录：看起来像任务"自己结束了"）。看门狗会认出这种暂停，窗口一恢复就自动继续；被别的窗口挡住没关系，但不能最小化。

另外等待类的超时（如跳过剧情）会在日志和报错里写明"当前在结算页/部署界面/战斗中/选关页面/体力弹窗/未知页面"，截图名也带这个页面名。
