# 新版界面（测试版，web_v2）

参考 NikkeMDA（MaaFramework 的 MXU 界面）的交互方式做的浏览器界面：左边是按**游戏板块**分组的任务勾选列表，中间是选中项的选项面板，右边是运行状态和最近日志；另有「全局设置」「运行日志」「画面」三页。旧的 Qt 桌面界面和旧的 web 页面都没有改动。

## 怎么打开

**Windows 窗口（推荐）**：桌面版（main.py / run.bat）关掉后，双击仓库里的 `run_v2.bat`（桌面快捷方式 `ok-gf2-v2.lnk`），它会先 `git pull` 再运行：

```
.venv\Scripts\python.exe tools\app_v2.py --port 8765
```

程序用 pywebview 开一个原生窗口显示新界面（依赖 `pywebview`，已加进 requirements.txt）。关掉窗口就退出。

**只起后端、用浏览器看**：

```
.venv\Scripts\python.exe tools\serve_web_v2.py            # 默认 127.0.0.1:8765
```

- 新版：http://127.0.0.1:8765/v2/
- 旧版 web 页面：http://127.0.0.1:8765/

两个页面共用同一套框架自带的 `/api` 接口，改哪一边的设置另一边都能看到。Web 模式和桌面版不能同时运行。

## 任务页的组织方式

目录在 `web_v2/catalog.json`，按主界面入口分 11 个板块，每一项对应「一键日常」里的一个开关键，以及只对这一项有意义的选项：

| 活动 | 情报补给 / 战前补给 | 情报和战前补给 | |
| 活动 | 闪耀星愿 | 闪耀星愿 | |
| 限时开启 | 活动自律（物资关卡） | 活动自律 | 当前物资关卡名称 |

| 公共区 / 委托 | 调度室派遣与领取 | 公共区/调度室 | 自主循环 |

- 勾选框直接写「一键日常」的开关；顶部「开始」按当前选中项决定运行一键日常还是某个独立任务。
- 列表上方的「全套日常 / 快速收菜 / 只打体力」是一键预设，只改勾选状态（对应 MXU 的 preset）。
- 一键日常跑过之后，每项后面会显示「今日已完成」「待重试」（来自每日记录）。
- 日常里有而目录里没归类的键会自动出现在「其它日常选项」组，不会丢。

## 全局设置页

- 「日常通用」：已确认启用游戏内全局自动功能、生成汇总文件、自动打开汇总文件、Exit After Task、多账户三项（它们挂在一键日常下，但对整轮生效）。
- 框架的全局组：Basic Options、Notification 等。
- 项目的全局组：阵容与助战（默认编队、借好友助战、助战规则）、体力（自动使用体力药）、调试（调试截图）。阵容与助战下面有一张「各场景单独设置」一览表，高亮和全局不一样的场景，可跳到对应板块或恢复全局。

## 阵容：默认 → 全局 → 板块单独设置

编队和借助战按三层取值，越后越优先：内置默认（编队1、借助战开）→ 全局设置页「阵容与助战」→ 各板块选项面板里的「阵容」卡片。

- 场景登记在 `src/core/lineup_config.py` 的 `SCOPES`（推图、竞技场、体力本、班组、尘烟前哨战、活动），每个场景在全局组里有 `<场景>编队`（留空=沿用）和可借助战场景的 `<场景>助战`（沿用全局/开/关）。数据只存这一份，旧界面也能看到。
- `catalog.json` 的条目用 `lineup_scopes` 声明用到哪些场景，选项面板就显示对应的「阵容」卡片：编队输入框的灰字是继承来的值，助战三段按钮标出全局当前值，单独设置过会显示「已单独设置」，「恢复全局」一键清掉。
- 加新场景：`SCOPES` 里加一行，再在 catalog 对应条目的 `lineup_scopes` 里写上，界面不用改代码。

## 实现

- `tools/serve_web_v2.py`：用框架的 `create_web_app` 建同一个 FastAPI 应用，再把 `web_v2/` 挂到 `/v2`。
- `web_v2/app.js`：纯浏览器端脚本，不需要构建。用到的接口：`/api/tasks`、`/api/tasks/{name}/config|start|action|config/reset`、`/api/settings`、`/api/settings/{group}/config`、`/api/status`、`/api/executor/pause|resume|stop-task`、`/api/logs`、`/api/tools/capture` + `/api/capture/image`、WebSocket `/api/events`。
- 选项控件按接口给的 `kind`（boolean/integer/number/select/list/multi_selection/multiline/text）渲染；联动隐藏由后端决定，改完配置会重新拉一次。

## 已知限制

- 还没有：拖拽调整执行顺序（一键日常的顺序固定在代码里）、多账户覆盖页、计划任务页。
- 「教化」目前代码里没有对应流程，活动层只做了喝水、吃饭、浇花和逸趣导算奖励。
